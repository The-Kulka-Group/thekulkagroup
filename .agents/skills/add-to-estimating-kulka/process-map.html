add-to-estimating-kulka

New-lead intake: cover sheet to job number to OneDrive folder to Monday / ProEst / BuildingConnected, with an explicit go-ahead before any write.

  1. 01

    Lead arrives

    Drawing set attached, or a Dropbox / Box link. Download or unzip as needed; if several PDFs, confirm which is the drawing set.

  2. 02

    Read cover sheet

    Pull project name and address from the cover (typically A-001).

  3. 03

    Verify next project number

    Cross-check the Monday log and OneDrive folder names (C##### / D#####). If they disagree, use the higher number and flag it in the wrap-up.

  4. 04

    Create OneDrive project folder

    Copy from the estimating template into the right parent. Folder is always created for a live intake.

  5. 05

    Log the job

    Write Monday, ProEst, and/or BuildingConnected for the combination this lead needs. Default is all that apply; skip only when the requester says so.

  6. 06

    Safeguards

    Duplicate or partial-run check first. Show every field for go-ahead before writing. Stop and ask rather than guess on division letter, priority, or estimate type.

Hard stops

  • Block: no PDF / ambiguous cover sheet, no folder, or failed verify twice.
  • Non-blocking: number mismatch across systems, or a system skipped by choice — log and continue.
