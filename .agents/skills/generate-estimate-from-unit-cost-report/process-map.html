generate-estimate-from-unit-cost-report

ProEst Estimate Unit Totals PDF → client SOW / pricing / four-column bid-leveling workbook. No retyped quantities. No silent zeros.

  1. 01

    CONFIRM

    Project name, job number, date, prepared-by, output folder.

  2. 02

    PARSE

    ProEst Estimate Unit Totals PDF → JSON via scripts/parse_proest_pdf.py.

  3. 03

    REVIEW

    Read every parser issue. Nothing ships unexplained.

  4. 04

    NOTES

    Add notes and markup labels to the JSON before build.

  5. 05

    BUILD

    Run scripts/build_sow_pricing_xlsx.py to the raw workbook.

  6. 06

    FINALIZE

    Run scripts/finalize_workbook.py so LibreOffice caches formula results. Never skip.

  7. 07

    VERIFY

    PDF spot-check: page 1, a dense page, the ladder, the SOV, and the notes sheet.

  8. 08

    RECONCILE

    Workbook TOTAL must match the ProEst grand total within a few cents.

  9. 09

    DELIVER

    Send the file, then drop it in the job folder.

Two hard rules

  • Rate = report_total ÷ qty. The printed ProEst rate is display only; store the derived rate so extensions land on the report’s own total.
  • Never skip finalize. Without the LibreOffice cache pass, money columns look blank outside Excel.
