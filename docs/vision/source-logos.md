# Vision source logos

Downloaded September 6, 2026 from each publisher's public website. The app serves these files locally so displaying a source does not send the visitor to a third-party image server. Logos retain their original colors and proportions. They identify the source; they do not imply endorsement.

Source names remain visible beside every logo. Images use empty alt text because the adjacent name already labels the source. Failed images fall back to initials, and source controls continue to work.
